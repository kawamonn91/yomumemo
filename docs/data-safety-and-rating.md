# データセーフティとコンテンツレーティングの回答

Play Console の2つの質問票にそのまま答えられるよう、回答と根拠をまとめてある。
**根拠まで書いてあるのは、後で機能を足したときに回答を見直す必要があるかどうかを
自分で判断できるようにするため。** 実装を変えたらここも見直すこと。

---

## データセーフティ

### 結論

**「アプリはユーザーデータを収集または共有していません」** と回答する。

### 根拠

Google の言う「収集」は、**端末の外へ送信すること**を指す。本アプリが送信するものを
すべて挙げると次のとおりで、いずれも Google が列挙するデータ型に当たらない。

| 送信するもの | 送信先 | 判断 |
|---|---|---|
| ISBN（本を特定する番号） | openBD / Google Books | 書籍の識別子であり、利用者個人に関する情報ではない |
| 購入処理に必要な情報 | Google Play | Google Play が取り扱う。アプリは決済情報を受け取らない |

**送信しないもの**（確認済み）:

- メモの本文・引用・本の情報 … 端末内の SQLite にのみ保存
- カメラ画像 … OCR は端末内で完結し、画像は保存も送信もしない
- 利用状況・クラッシュ情報 … 解析 SDK を組み込んでいない
- 広告ID … 広告を表示しない

### 個別の質問への答え

| 質問 | 回答 |
|---|---|
| 収集または共有するデータの種類 | いずれも該当なし |
| データは転送時に暗号化されますか | （収集しないため回答不要。ただし通信はすべて HTTPS） |
| ユーザーはデータの削除を要求できますか | （収集しないため回答不要） |
| アプリに広告が含まれますか | いいえ |

### 補足: Android の自動バックアップについて

`allowBackup="true"` により、端末の設定に応じてアプリのデータが
**利用者自身の Google アカウント**へバックアップされることがある。
これは Android の標準機能によるもので、開発者はその内容を参照できず、
開発者による「収集」には当たらない。プライバシーポリシーには記載済み。

無効にしたい場合は `AndroidManifest.xml` の `android:allowBackup` を `false` にする。
ただし利用者が端末を失ったときにメモも失われるため、有効のままを推奨する。

## コンテンツレーティング（IARC 質問票）

### カテゴリ選択

**「リファレンス、ニュース、または教育」** を選ぶ。

### 各設問への回答

| 設問 | 回答 |
|---|---|
| 暴力的な表現 | いいえ |
| 性的な表現・ヌード | いいえ |
| 冒とく的な表現 | いいえ |
| 規制薬物・アルコール・たばこ | いいえ |
| ギャンブル・賭博の要素 | いいえ |
| 恐怖を感じさせる表現 | いいえ |
| ユーザー同士が交流できますか | **いいえ**（本アプリにSNS機能・共有機能はなく、他の利用者と繋がる手段がない） |
| ユーザーの現在地を共有しますか | いいえ |
| ユーザーの個人情報を第三者と共有しますか | いいえ |
| ユーザーが作成したコンテンツを他の利用者が見られますか | **いいえ**（メモは端末内に留まり、公開する手段がない） |
| デジタル購入がありますか | **はい**（買い切りのプレミアム解除） |

### 想定される結果

全年齢対象（IARC 3+ / 日本では CERO A 相当）。

> **注意**: 「ユーザー同士が交流できますか」に誤って「はい」と答えると、
> レーティングが上がるうえ、追加の質問（報告機能の有無など）が発生する。
> 本アプリに交流機能はないので「いいえ」で正しい。
> 将来メモの共有機能を足す場合は、ここを見直すこと。

## 広告 ID の申告

`AndroidManifest.xml` に広告 ID の権限を宣言していないため、
「アプリは広告 ID を使用しますか」には **いいえ** と答える。
